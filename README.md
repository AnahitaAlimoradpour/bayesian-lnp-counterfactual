# Bayesian Uncertainty-Aware & Counterfactual LNP Design

This repository contains a robust, Python-based Bayesian machine learning pipeline designed for modeling and optimizing Lipid Nanoparticle (LNP) delivery systems. Developed to assist in advanced computational pharmaceutics and drug delivery research.

## Features
- **Bayesian Regression via PyMC**: Accounts for parameter uncertainty rather than relying solely on point estimates.
- **Epistemic Uncertainty Quantification**: Evaluates model confidence alongside transfection efficacy predictions.
- **Counterfactual Optimization**: Answers "What-If" scenarios on lipid molar ratios and N/P parameters.

## Tech Stack
- Python 3.13
- PyMC & ArviZ
- NumPy & Pandas
